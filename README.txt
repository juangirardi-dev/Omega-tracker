OMEGA TRACKER – INSTALLATION PÅ IPHONE

Paketet är en PWA. Den sparar träningsdata lokalt i webbläsaren på din iPhone.
Ingen inloggning eller molnlagring används.

PUBLICERA GRATIS MED GITHUB PAGES
1. Skapa/logga in på ett GitHub-konto.
2. Skapa ett nytt publikt repository, exempelvis omega-tracker.
3. Ladda upp ALLA fem filer: index.html, manifest.json, sw.js, icon-192.png, icon-512.png.
4. Gå till repository Settings > Pages.
5. Under Build and deployment välj Deploy from a branch, branch main och folder /(root). Spara.
6. Vänta tills GitHub visar webbplatsens adress.

INSTALLERA PÅ IPHONE
1. Öppna webbplatsadressen i Safari (inte inne i en annan app).
2. Tryck på Dela.
3. Välj Lägg till på hemskärmen.
4. Kontrollera namnet OMEGA och tryck Lägg till.

VIKTIGT
- Första gången krävs internet för att öppna webbplatsen och cachelagra appen.
- Därefter kan appens grundfunktioner fungera offline.
- Träningsdata sparas lokalt på den här enheten. Rensa inte Safaris webbplatsdata om du vill behålla historiken.
- Lokal lagring är inte en säkerhetskopia. Export/synkronisering kan läggas till senare.
- GitHub Pages är gratis för publika repositories. Appen är inte publicerad i App Store.
